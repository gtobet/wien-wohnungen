    Aktualisieren einrichten

    Der Button startet die Suche auf GitHub. Dafür braucht diese Seite einmalig einen persönlichen GitHub-Schlüssel. Er wird nur in diesem Browser gespeichert.

    1. Öffne github.com/settings/personal-access-tokens/new.
    2. Name beliebig, Ablaufdatum nach Wunsch. Bei Repository access „Only select repositories“ → wien-wohnungen.
    3. Bei Permissions → Repository permissions den Punkt Actions auf „Read and write“ stellen.
    4. „Generate token“ klicken und den Schlüssel hier einfügen.

    Ohne Schlüssel kannst du die Suche auch auf GitHub unter „Run workflow“ starten.
